## 🛠️ Stack technique

### Frontend
- **React 19** avec **Vite** ⚡
- **Tailwind CSS** pour le styling 🎨
- **Framer Motion** pour les animations fluides ✨
- **Three.js** & **@react-three/fiber** pour la 3D 🎮
- **GSAP** & **ScrollTrigger** pour les animations de scroll 🎪
- **React Router Dom** pour la navigation 🧭

### Animations & Interactions
- **Locomotive Scroll** pour un scroll butter smooth 🧈
- **Typed.js** pour les effets de machine à écrire ⌨️
- **Custom Cursor** personnalisé 🖱️
- **Réseau de neurones 3D** interactif 🧠

### Backend (à venir)
- **Supabase** pour la base de données et l'authentification 🗄️
- Gestion des demandes de devis et contacts 📬

## 🚀 Installation & Développement

```bash
# Cloner le projet
git clone [votre-repo]
cd PortfolioTWA

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour la production
npm run build

# Prévisualiser le build
npm run preview
```
